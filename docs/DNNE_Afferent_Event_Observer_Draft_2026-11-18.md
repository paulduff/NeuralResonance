`AvatarAfferentCrossing` and `AvatarAfferentEventObserver` are isolated drafts.
The full test project builds with zero warnings/errors in
`D:/DNNE-build-work/afferent-observation-authoring-20261118`. Twenty prospective

The observer follows a single explicitly identified cable output node and a
declared voltage threshold. It reads accepted interval endpoints and actual
full-kernel derivatives under the same held input, then localizes an upward
crossing with a monotone cubic. It neither resets voltage nor injects current,
imposes a firing rate, settles the cell, nor invents a refractory filter.
Initial-above-threshold state is not an event. Hidden or ambiguous crossings
cause an explicit observation failure, requiring a finer interval.

One owner advances a fresh identified cell. An exact retry returns the same
receipt without advancing or reevaluating; changed input, skipped/stale clocks
and external advancement are rejected. Event identity includes session, cell,
source, observation site, model/criterion fingerprint and ordinal. A failure
after physical advancement preserves the accepted physical prefix and blocks
further observation; it does not roll back biology or commit a fabricated event.

Proposed checks include analytic crossing controls, passive two-capacitor
refinement, unchanged accepted source/gates/ledgers, held-input boundaries,
stable identity, exact retries, bath gauge invariance and failure-prefix
preservation. Passive diagnostic threshold crossings are not sensory firing.
Persistence/warm attachment and physiological thresholds are not qualified.

The live `PhysicalBodyTransducerRuntime` still synthesizes frame/activation
stimuli through its existing vestibular population path. Connecting a new
neuronal source will require declared central contacts and an explicit owner
boundary, avoiding re-simulation of an already owned afferent or generic target
remapping. This draft does not repair or qualify that live pathway.
