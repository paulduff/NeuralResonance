## Owned recording lifecycle

`native_capture_store.py` initializes only when this run's `native-bridge` raw
root and both publication directories are absent. It records a fresh ownership
identity in the run and backup before capture. Existing captures cannot be
adopted; the interface has no migration, overwrite or automatic-resume operation.

Each condition is packed by the unchanged qualified archive writer, copied to
the backup destination, flushed, hash checked, and verified member by member.
The original completion-record hash must match. Raw data is still present at
this point. Release separately rechecks both archives, the exact raw inventory,
every raw hash, and ownership; it writes durable intent records before removal.

Only individually enumerated, hash-verified files inside that new condition can
be unlinked. Ancestors and target paths reject junctions/reparse points before
resolution and removal. Empty directories are recorded and removed only with
nonrecursive `rmdir`. There are no wildcard or recursive deletion commands.
An unexpected remaining file prevents directory removal. Interrupted publication
retains its raw prefix; interrupted release retains both complete archives and
all remaining raw files, and refuses automatic continuation. Existing saves,
old raw captures and failed historical studies are never cleanup targets.

A complete numerical/qualitative failure discovered later still retains every
original file byte in both archives. A failure during native recording leaves
its incomplete raw condition intact. This distinction is explicit: archive
publication proves byte preservation, not that the recorded experiment passed.

Work and backup are under `D:/DNNE-build-work` and
`D:/DNNE-desktop-runs/UnityWorld`. Both new copies share D: and do not provide
independent-drive redundancy. Preparation requires 30 GiB free, native admission
requires 20 GiB, and each publication boundary retains a 10 GiB reserve. Old
independent C:/D: captures remain untouched. Successful conditions cease to occupy
a large raw staging tree before the next condition starts.
