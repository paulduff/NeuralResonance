## Recipient contract

`IsolatedSynapticTargets` binds a source instance, structure, neuron, projection,
transmitter, feedback flag and synthetic flag to one receiver cell. It copies
and canonically orders declarations, rejects duplicate/conflicting/out-of-range
recipients and exposes immutable entries. An exact declared contact resolves
before the generic cortical mapping. Unlisted traffic retains its existing route.

This internal constructor option requires an empty absolute state directory, an
`isolated-` instance and a full cortical population. Public service construction
does not enable it. The map version and fingerprint participate in the isolated
save fingerprint; the old null-map fingerprint stays unchanged. No old state is
loaded or migrated. The diagnostic model-status text identifies explicit isolated
recipients and outstanding receptor/arbor calibration.

The map supplies anatomy, not transmitter levels or a learning result. Actual
arrivals still enter the existing cell's receptor/local-modulation mechanisms;
only that cell's connected contacts see its modulation. It neither broadcasts a
global teaching scalar nor replaces the postsynaptic trace with sender activity.
The existing local-learning equations, plasticity budget and original assertion
are unchanged. This does not calibrate the reduced ACh/DA receptor model or turn
the derived consolidation score into a biological state.
