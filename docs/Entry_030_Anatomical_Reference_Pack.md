# Folded Archive Entry 030 — Anatomical Reference Pack

## Purpose

This entry establishes a canon visual reference pack for biological validation of the Neural Resonance Engine brain geometry and renderer.

The aim is not to make the renderer artistically brain-like in a generic sense. The aim is to constrain future geometry work using stable anatomical references grouped by function:

- outer silhouette
- superior surface folds
- lobe boundaries
- sulci and gyri landmarks
- medial/internal landmark validation

## Why this matters

Historically, renderer work can drift because visual judgement alone is too subjective. A reference pack reduces that drift by giving each camera view and each anatomical correction a stable comparison set.

This is especially important for:

- superior view fold patterns
- central sulcus placement
- frontal/parietal boundary checks
- temporal lobe side placement
- occipital rear placement
- corpus callosum neighbourhood validation via future medial references

## Intended use

This pack should be consulted before and after any of the following:

- hemisphere outline edits
- gyrification / sulcal surface edits
- lobe colour mapping changes
- coordinate system remaps
- camera preset redefinitions
- callosal / thalamic / hippocampal position corrections

## Validation order

1. Whole-brain silhouette
2. Superior view folds and midline split
3. Lateral lobe boundaries
4. Central sulcus and pre/postcentral zones
5. Medial wall and midline structures
6. Fine detail refinement

## Archive judgement

This is a support entry, not a behavioural one. It improves anatomical discipline and reduces visual regression risk without changing runtime cognition.
