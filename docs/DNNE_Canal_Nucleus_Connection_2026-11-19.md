sensory cell and its observed-event outbox. Its recording sink acknowledged

It is an isolated candidate, with no live service, Unity or editor selector.

The constructor attaches the actual fresh canal/sensory owner, explicit routes,
receiver step and declared substrate supply. It creates a separate fresh nucleus
save directory and restores the process environment immediately. Existing saves
cannot be loaded, replaced or silently upgraded. It does not settle or reset the
sensory state, add a second afferent, synthesize spikes or change receptor/learning
equations. Anatomical routes, release parameters and reference supply remain
explicit uncalibrated choices.

Head consumption and sensory advancement use the existing owner. Publication
seals its original quiet/firing packet and admits it through the existing atomic
ingress. The nucleus advances only on its own fixed integer-indexed grid, within
completed source time plus the shortest remaining conduction delay. Packet
boundaries do not force partial receiving steps. Each frame is bounded to 4,096
receiver ticks; further source/body advancement waits for consumer acknowledgement.

The immutable serialized frame retains the original packet, admission evidence,
actual receiving-contact deliveries and all original receiving step/output
messages. Exact publication retries return that same frame. Only its exact
acknowledgement releases the source packet and, where complete, the mechanical
trace. Quiet intervals carry time without inventing afferent events. Changed or
stale acknowledgements cannot release a newer frame. External source advancement
or head consumption is rejected before the receiver moves.

A receiving failure preserves its source packet, earlier drained output frames,
actual delivery prefix and remaining undrained output. The connection then rejects
resumption; it cannot repeat partially integrated receiving biology. This is
in-process ownership, not a durable cross-process checkpoint or cluster protocol.
One afferent source and an existing full nucleus do not qualify multiple-source
modulation, physiological sensory firing, full brain authority or balance.
